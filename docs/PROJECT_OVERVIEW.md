# Project Overview - StudyFlow

## 1. Ringkasan Project
StudyFlow adalah prototype website produktivitas belajar untuk membantu mahasiswa mengatur tugas, menggunakan teknologi

## 2. Tujuan
- Menerapkan HTML semantic dalam struktur halaman web.
- Menerapkan Tailwind CSS untuk styling responsif.
- Menerapkan JavaScript dasar untuk interaksi halaman.
- Melatih workflow Git dan GitHub dalam kerja tim.
- Membuat prototype yang ringan, mudah dijalankan, dan mudah dijelaskan.

## 3. Target Pengguna
- Mahasiswa
- Pelajar
- Pengguna yang ingin mengatur jadwal belajar dan mengulang materi secara aktif

## 4. Scope MVP
MVP yang dikerjakan pada tahap awal:
- Landing page yang menjelaskan StudyFlow.
- Halaman task sederhana.
- Halaman Pomodoro dengan kontrol dasar.
- Halaman Flashcard dengan flip dan next card.
- Navigasi antar halaman fitur.

## 5. Out of Scope Sementara
Fitur berikut menjadi pengembangan lanjutan, bukan target awal:
- Login/register.
- Backend/database online.
- React/Vite.
- Statistik kompleks.
- Sinkronisasi cloud.
- Notifikasi browser lengkap.
- Sistem spaced repetition penuh.

## 6. Alasan Teknologi
Saat ini project menggunakan HTML, Tailwind CDN, dan JavaScript dasar karena sesuai dengan tahap pembelajaran WCD
